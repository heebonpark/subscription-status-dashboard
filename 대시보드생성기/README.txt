청약현황 대시보드 생성기
=========================

실적 CSV 파일을 선택하면 청약현황 대시보드(HTML) 파일을 자동으로 만들어주는
Windows용 GUI 프로그램입니다.


1. 폴더 구성
------------
  app.py          실제 프로그램 (Python)
  template.html   대시보드 화면 템플릿 (수정하지 마세요)
  실행.bat        더블클릭으로 프로그램을 실행하는 파일
  exe만들기.bat   Python 없이도 실행되는 단일 exe 파일을 만들어주는 도구
  config.json     마지막에 사용한 파일 경로가 자동 저장되는 설정 파일 (자동 생성)


2. 실행 방법 (가장 간단한 방법)
--------------------------------
  1) "실행.bat" 파일을 더블클릭합니다.
  2) 이 컴퓨터에 Python이 설치되어 있지 않다면 안내 메시지가 뜹니다.
     https://www.python.org/downloads/ 에서 Python 3.10 이상을 내려받아 설치하세요.
     설치 화면에서 반드시 "Add python.exe to PATH" 체크박스를 선택해야 합니다.
  3) 설치 후 "실행.bat"을 다시 실행하면 프로그램 창이 뜹니다.

  ※ tkinter(화면 라이브러리)는 Python 표준 설치에 기본 포함되어 있어
     별도로 pip install 할 것이 없습니다.


3. 사용 방법
------------
  1) [찾아보기...] 버튼으로 실적 CSV 파일을 선택합니다.
  2) 저장할 대시보드 HTML 파일 위치가 자동으로 채워집니다 (직접 바꿀 수 있음).
  3) [대시보드 생성] 버튼을 누르면 처리 로그가 표시되고,
     완료되면 자동으로 브라우저에서 대시보드가 열립니다.
     (자동으로 열지 않으려면 "생성 후 브라우저에서 바로 열기" 체크를 해제하세요)


4. CSV 파일 요구사항
---------------------
  다음 컬럼(헤더)이 반드시 포함되어야 합니다:
    영업지사명, 영업자명, 영업자소속, 청약일자, 계약상태(중), 계약번호, 상호, KTT월정료
  "추천자명" 컬럼은 있으면 활용하고, 없어도 동작합니다.

  인코딩은 UTF-8 또는 CP949(EUC-KR, 한글 Windows 기본 CSV 인코딩) 모두 자동 인식합니다.

  계약상태(중) 값은 다음 규칙으로 분류됩니다:
    - "취소" 또는 "해지"가 포함된 값  → 취소/해지
    - "유지" 또는 "명변유지"          → 유지
    - 그 외 모든 값 (청약승인/청약등록/일시정지 등) → 청약(진행)

  이 규칙은 대시보드 화면 자체의 "파일 업로드" 기능과 완전히 동일합니다.


5. Python 없이 실행하고 싶다면 (exe 만들기)
--------------------------------------------
  1) "exe만들기.bat"을 더블클릭합니다. (최초 1회만 Python + 인터넷 연결 필요)
  2) 빌드가 끝나면 dist 폴더 안에 "청약현황대시보드생성기.exe" 파일이 생성됩니다.
  3) 이 exe 파일 하나만 다른 컴퓨터로 복사해도 Python 설치 없이 바로 실행됩니다.
     (내부에 template.html이 함께 포함되어 빌드됩니다)


6. 문제 해결
------------
  - "필수 컬럼이 없습니다" 오류
      CSV 헤더 이름이 위 4번 항목과 정확히 일치하는지 확인하세요.

  - "CSV 파일의 인코딩을 인식할 수 없습니다" 오류
      원본 프로그램(ERP/CRM 등)에서 CSV로 다시 내보내 보세요.

  - 실행.bat을 눌렀는데 창이 바로 뜨지 않고 지연됨
      검은 콘솔 창이 잠깐 떴다 사라진 뒤, 실제 프로그램 창이 뜨기까지
      몇 초 정도 걸리는 것은 정상입니다 (Python/Tk 초기화 시간).
      백신 프로그램(Windows Defender 등)이 처음 실행되는 파일을 검사하면
      수십 초까지 걸릴 수도 있습니다 — 한 번 정상 실행되면 이후에는 빨라집니다.
      1분 넘게 아무 반응이 없다면:
        1) 작업 관리자에서 python.exe / pythonw.exe 프로세스가 떠 있는지 확인
        2) 이 폴더의 error.log 파일에 오류가 기록됐는지 확인
        3) 명령 프롬프트를 열어 이 폴더에서 직접 "py app.py" (또는 "python app.py")를
           실행해 오류 메시지가 콘솔에 바로 보이는지 확인

  - "template.html 파일을 찾을 수 없습니다" 오류
      app.py와 template.html이 반드시 같은 폴더에 있어야 합니다.

  - 그 외 오류
      프로그램 폴더에 생성되는 error.log 파일에 자세한 내용이 기록됩니다.
