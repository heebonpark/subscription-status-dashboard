# subscription-status-dashboard

청약(구독/계약) 현황을 지사·영업자·기간별로 분석하는 대시보드와, 실적 CSV로부터
그 대시보드(HTML)를 자동 생성하는 Windows용 GUI 도구입니다.

## 구성

- **대시보드생성기/** — CSV를 선택하면 대시보드 HTML 파일을 만들어주는 Python GUI 프로그램
  (`실행.bat` 더블클릭으로 실행, 자세한 내용은 [대시보드생성기/README.txt](대시보드생성기/README.txt) 참고)

## 대시보드 기능

- 지사·영업자·청약일자별 실적 현황 (건수 / 월정료)
- 유지 · 청약(진행) · 취소·해지 상태별 분석, 취소율 · 유지전환율
- 영업자 성과 매트릭스, TOP N 리더보드
- 월별 추이 (이동평균 · 신뢰구간 · 이상치 자동 감지)
- 연도별 비교 (원값 / 계절지수 / YoY 증감), MoM 요약
- 목표 설정 및 통계 기반(선형회귀 · Holt 지수평활) 연말 예측
- 라이트/다크 테마, 모바일 대응

## 데이터 안내

이 저장소는 **공개(public)** 저장소이므로 실제 고객·영업 데이터가 담긴 CSV 원본과
데이터가 삽입된 대시보드 HTML은 커밋하지 않습니다 (`.gitignore` 참고).
대시보드 화면 구조만 담긴 데이터 없는 템플릿은 `대시보드생성기/template.html`에 포함되어 있습니다.
